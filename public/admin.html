ဓာတ်ပုံ အမည် / မော်ဒယ် တံဆိပ် / kVA ဈေးနှုန်း (သိန်း) နာရီ / အခြေအနေ Status လုပ်ဆောင်ချက်

မီးစက် အငှား ဘိုကင်များ စီမံခန့်ခွဲမှု

သုံးစွဲသူများထံမှ တင်ပြလာသော အငှားတောင်းဆိုချက်များ

ဘိုကင်ကုဒ် အမည် / ဖုန်း ငှားရမ်းမည့်ရက်စွဲ ပို့ဆောင်ရမည့်လိပ်စာ ခန့်မှန်းတန်ဖိုး Status ပြောင်းလဲရန်

ပြုပြင်ရေး လက်မှတ်များ (Repair Service Tickets)

အင်ဂျင်နီယာ တာဝန်ပေးခြင်းနှင့် ကုန်ကျစရိတ် မှတ်တမ်းတင်ခြင်း

လက်မှတ်ကုဒ် အမည် / ဖုန်း / လိပ်စာ စက်အမျိုးအစား / ပြဿနာ အရေးပေါ်အဆင့် တာဝန်ကျအင်ဂျင်နီယာ Status စီမံရန်

မီးစက်ပြန်ရောင်းရန် တင်ပြချက်များ (Customer Submissions)

သုံးစွဲသူများမှ ရောင်းချလိုသော စက်ဟောင်း အချက်အလက်များ

ကုဒ် ရောင်းချသူ / ဖုန်း မီးစက် / kVA မျှော်မှန်းရောင်းဈေး စက်အခြေအနေ Status ပြောင်းလဲရန်

မီးစက် ဝယ်ယူရန် မေးမြန်းမှုများ (Purchase Orders)

ဝက်ဘ်ဆိုက်မှ မီးစက်ဝယ်ယူရန် တောင်းဆိုထားသော အမှာစာများ

အမှာစာကုဒ် ဝယ်ယူသူ / ဖုန်း မီးစက် အမည် ပို့ဆောင်မည့်နေရာ Status ပြောင်းလဲရန်
